D24 ADM customer map

Open index.html using an HTTPS static host or localhost. Files: index.html, styles.css, app.js, data.js, map-data.json and all-adm-addresses.csv. No build step is required.

ADM buttons 044, 047, 240, 344, 431 and 440 are independent toggles. All are selected by default. Colors stay consistent as selections change. Shared-location markers show colored segments for every selected ADM at that point. Popups list all customers at that point. Select all and Clear all buttons are provided. Search and CSV export respect the selected ADMs and location filters.

Mobile automatically requests location access and follows within a 4 km radius. Pause/Resume stops and restarts map centering; dragging the map or opening a customer pauses following. Location updates remain local to the browser. GPS requires HTTPS or localhost; Leaflet and OpenStreetMap tiles require internet access.

Source: D24 app 2026 ADM.xlsx. Only nonempty customer rows were imported. ADM codes preserve leading zeros. The provided address columns are used.
